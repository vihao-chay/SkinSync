# SkinSync Design System

A premium, wellness-focused design system for a personalized AI skincare experience. The system balances clinical data density with a calming, high-end aesthetic.

## Visual Identity

### Color Palette
- **Primary (Sage Green):** `#8a9a5b` - Used for primary actions, brand presence, and health indicators.
- **Surface (Ivory):** `#faf9f5` - Main background color to create a clean, airy feel.
- **Surface Container:** `#f4f4f0` - Used for cards and secondary sections.
- **On-Surface (Charcoal):** `#36454f` - High-contrast text for maximum readability.
- **Accent (Soft Coral):** `#f4a460` - Subtle warmth for highlights or specific notifications.
- **Accent (Warm Gold):** `#d4af37` - Used for premium status or "excellent" scores.

### Typography
- **Primary Font:** `Playfair Display` - Sophisticated serif for headings and brand elements.
- **Secondary Font:** `Inter` or `System Sans-Serif` - Clean, legible font for body copy, data points, and UI labels.

### Shapes & Elevation
- **Corner Radius:** `8px` (Round Eight) - Softened edges for a friendly yet structured look.
- **Elevation:** Low-profile shadows and glass-morphism effects (backdrop-blur) for a modern, layered feel.

## UI Components

### Navigation
- **Top App Bar:** Glass-morphism effect (`backdrop-blur-md`), centered brand logo in Playfair Display.
- **Bottom Navigation:** Icon + Label persistent bar. Active state highlighted with a soft background pill.

### Data Visualization
- **Circular Health Score:** Bold percentage in the center, utilizing the primary brand color to indicate progress or health.
- **Metric Cards:** Compact cards for skin concerns (Acne, Redness, etc.) with color-coded status indicators.

### Interaction Elements
- **Primary Button:** Solid Sage Green background with white text, 8px radius.
- **Secondary Button:** Outlined or soft surface-container background.
- **Segmented Controls:** Pill-shaped toggles for switching views (e.g., Morning/Evening).

### Content Cards
- **Product Card:** High-quality imagery, clear brand/name hierarchy, and AI Match percentage badges.
- **Routine Step:** Checklist-style cards with clear status indicators and concise instructions.

## Design Philosophy
SkinSync should feel like a **digital esthetician**: expert, data-driven, yet soothing. Whitespace is used intentionally to prevent the "data-rich" screens from feeling cluttered. Every AI-generated insight is paired with clear reasoning to build user trust.
